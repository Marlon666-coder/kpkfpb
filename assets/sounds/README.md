Folder suara (opsional). Tanpa file pun game tetap berbunyi (bunyi dibuat oleh browser).
Untuk memakai suara sendiri, taruh file (mis. benar.mp3) di sini, lalu isi `CONFIG.soundFiles`
di script.js, contoh: `correct: "assets/sounds/benar.mp3"`.
Nama bunyi yang tersedia: click, hop, correct, wrong, coin, win.
